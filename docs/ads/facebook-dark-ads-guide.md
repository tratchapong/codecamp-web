### 📝 Copywriting ชุดที่ 1

#### Primary Text (ข้อความโพสต์ยาว):
```text
เรียนเขียนโค้ดตามคลิปมาหลายเดือน ทำ To-do list ได้ ทำเว็บตามคลิปได้หมด...
แต่พอเปิดเว็บหางานดู Requirement จริง กลับ "ไม่กล้าส่งใบสมัครสักที่" ใครกำลังติดปัญหานี้อยู่บ้าง?
.
นี่คือสิ่งที่เรียกว่า "Tutorial Hell" หรือกับดักการเรียนเขียนโปรแกรมที่กลืนเวลาคนอยากเปลี่ยนสายมากที่สุด
.
ความจริงในตลาด Developer ปี 2026 คือ:
❌ บริษัทไม่ได้ต้องการคนที่จำ Syntax ได้ (เพราะ AI เขียนแทนได้หมดแล้ว)
❌ บริษัทไม่ได้มองหาคนที่แค่ก๊อปโค้ดตามคลิป YouTube ได้
.
แต่สิ่งที่ทำให้คนไม่มีวุฒิคอมฯ "ได้งานจริง" คือ:
1. การเข้าใจ Git Flow และการทำงานร่วมกันเป็นทีมแบบ Agile
2. ทักษะการดีบักปัญหาจริงที่ไม่มีในเฉลย
3. การมีโปรเจกต์ระดับ Enterprise ที่คิด Logic และออกแบบ Database เองทั้งหมด
4. และสิ่งที่ยากที่สุด... "การก้าวผ่านกำแพงประสบการณ์แรก"
.
ถอดบทเรียนจากคนเปลี่ยนสายกว่า 22 รุ่น (900+ คน) สู่คู่มือ 4 ขั้นตอนปลดล็อกวงจรเรียนเองแล้วตัน เพื่อให้คุณก้าวสู่ Developer อาชีพได้อย่างมั่นใจ
.
👇 อ่านคู่มือและ Roadmap ฉบับเต็มได้ที่ลิงก์ด้านล่าง (อ่านฟรี ไม่มีค่าใช้จ่าย)
```

#### Headline (พาดหัวบนการ์ดลิงก์):
`ถอดบทเรียน 900+ คน: ทำไมยิ่งเรียนตามคลิป ยิ่งไม่กล้าสมัครงาน?`

#### Description (คำบรรยายสั้นใต้พาดหัว):
`คู่มือ 4 สเต็ปเปลี่ยนสายสู่ Developer ปี 2026 ฉบับคนเริ่มต้นจากศูนย์`

#### Call to Action (ปุ่ม):
`เรียนรู้เพิ่มเติม` (Learn More)

#### 🎨 แนวทาง Visual / รูปภาพโฆษณา (แนะนำทำ A/B Test):
1. **ภาพ Infographic:** เปรียบเทียบฝั่งซ้าย "เรียนตาม YouTube 6 เดือน (ทำตามได้ แต่คิดเองไม่เป็น, ไม่มีคนแก้บั๊ก, ไม่กล้าสมัครงาน)" VS ฝั่งขวา "Bootcamp + Real Project (ฝึก Git Flow, โค้ชประกบ, มีสิทธิ์ฝึกงานสะสมประสบการณ์)"
2. **ภาพแนว Minimal Text:** พื้นหลังสีเข้ม ตัวหนังสือสีขาว-ส้มเด่นชัด: *"เคยรู้สึกไหม? ยิ่งดูคลิปสอนโค้ดเยอะเท่าไหร่... ยิ่งรู้สึกว่าตัวเองยังไม่พร้อมทำงานจริงสักที"*

### 📝 Copywriting ชุดที่ 2

#### Primary Text (ข้อความโพสต์ยาว):
```text
"จบไม่ตรงสาย ไม่มีพอร์ตระดับบริษัท แล้วใครจะกล้ารับทำงาน?"
.
นี่คือกำแพงที่สูงที่สุดและเจ็บปวดที่สุดของคนอยากย้ายสายงาน...
ต่อให้ทุ่มเวลาเรียนจนเขียนเว็บเป็น แต่พอไปสมัครงาน มักจะเจอข้อความเดียวกัน:
"ต้องการประสบการณ์ทำงานอย่างน้อย 1-2 ปี"
.
กลายเป็นลูปที่แก้ไม่ตก: "ไม่มีประสบการณ์จึงไม่ได้งาน — แต่ถ้าไม่ได้งาน แล้วจะมีประสบการณ์ได้ยังไง?"
.
นี่คือเหตุผลที่ในรุ่น #24 (รอบ Onsite) CodeCamp ตัดสินใจเพิ่ม:
⭐ "สิทธิ์ประสานหาที่ฝึกงานพาร์ทเนอร์" เข้ามารองรับผู้เรียนหลังจบหลักสูตร!
.
เพื่อให้คุณ:
✅ ไม่ต้องเคว้งหลังเรียนจบ
✅ ได้สะสมประสบการณ์จริงในโปรดักชัน เพื่อเขียนลง Resume ได้อย่างเต็มภาคภูมิ
✅ เปลี่ยนสถานะจาก "คนเรียนคอร์สออนไลน์" เป็น "คนที่เคยผ่านงานจริงในบริษัท"
.
เรียนสด Onsite เข้มข้น 3.5 เดือน ทำ Final Project เดี่ยวแบบจัดเต็ม มีพี่เลี้ยงโค้ดประกบทุกวัน ไม่ทิ้งใครไว้ข้างหลัง
.
⏳ รุ่น #24 เปิดเรียน 5 ต.ค. 69 นี้ (จำกัดรอบละไม่เกิน 20 ที่นั่ง เพื่อให้โค้ชประกบและตรวจโค้ดได้เป็นรายบุคคล)
.
อ่านเจาะลึก Blueprint การเตรียมตัว และรายละเอียดสิทธิ์ฝึกงานได้ที่นี่ 👇
```

#### Headline (พาดหัวบนการ์ดลิงก์):
`แก้จุดตายคนเปลี่ยนสาย: ปลดล็อกกำแพง "ไม่มีประสบการณ์แรก"`

#### Description (คำบรรยายสั้นใต้พาดหัว):

#### Call to Action (ปุ่ม):

## ⚙️ Checklist การตั้งค่าแคมเปญใน Meta Ads Manager

1. **ตั้งชื่อ Campaign:** `[CONV/TRAFFIC] - Career Switch Guide - Sept 2026`
2. **Ad Set Level:**
   - Budget: แนะนำเริ่มต้น 300 - 500 บาท/วัน (แบ่ง Ad Set ละ 150 - 250 บาท)
   - Placement: Facebook Feeds, Instagram Feeds (ปิด Audience Network เพื่อคัด Traffic บอทออก)
   - Age: 22 - 38 ปี (ครอบคลุมเด็กจบใหม่ที่อยากรีบย้ายสาย และคนทำงานประจำ 2-7 ปีที่เริ่มตัน)
3. **Ad Level (Dark Post):**
   - เลือก **Create Ad** (แทนการเลือก Use Existing Post)
   - ใส่ Primary Text, Headline, URL ที่มี UTM Tracking
   - เช็ค Meta Pixel ว่าทำงานและตรวจจับหน้า `/guide/switch-to-developer/` สมบูรณ์
4. **Follow-up เมื่อมีคนทัก LINE:**
   - ตั้ง Quick Reply ใน LINE Official สำหรับตอบคำถามสิทธิ์ฝึกงานทันที เช่น:
     - *"สิทธิ์ฝึกงานพาร์ทเนอร์รองรับคอร์ส Onsite รุ่น #24 ที่จะเริ่มเรียน 5 ต.ค. นี้ค่ะ..."*
     - ส่งลิงก์หน้าคอร์ส Onsite หรือเสนอโทรคุยปรึกษาพื้นฐาน (Career Consultant Call) เพื่อปิดการขาย
