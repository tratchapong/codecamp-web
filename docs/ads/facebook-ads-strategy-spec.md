> **สถานการณ์ปัจจุบัน:** รับ 4/20 ที่นั่ง (ยังขาดอีก 16 ที่นั่ง) | แอดเก่าแบบ "เร่งโค้งสุดท้าย" เกิดอาการ Ad Fatigue และยอดเงียบ  
> **แกนการแก้ปัญหา:** ปรับเปลี่ยนแนวทางจากการฮาร์ดเซลส์เร่งปิดการขาย มาเป็น **"Full-Funnel Content-Driven (ท่าบทความ Advertorial + Retargeting แยกบทบาทชัดเจน)"**

## 1. การตัดสินใจเชิงกลยุทธ์: แก้โพสต์เดิม VS สื่อสารใหม่

| มิติเปรียบเทียบ | แก้ข้อความในแอดเดิม ❌ | สร้างแอดใหม่สื่อสารใหม่ (ท่าบทความ) ✅ |
| :--- | :--- | :--- |
| **ผลต่อ Facebook AI** | รีเซ็ต Learning Phase ข้อมูลเดิมสูญเปล่า | ระบบเริ่มหา Audience Segment ใหม่ที่ชอบเสพเนื้อหา |
| **พฤติกรรมผู้บริโภค** | คนเห็นแอดเดิมซ้ำๆ จนเบื่อ (Ad Fatigue) | สะดุดตากับ Hook ใหม่ที่แทงใจดำเรื่องการเรียนเองแล้วตัน |
| **จิตวิทยาการขาย (65k)** | เร่งคนที่ไม่พร้อมซื้อ ยิ่งทำให้ดูขายไม่ออก | กล่อมด้วยเหตุผล ปลดล็อกความกลัวเรื่อง "ไม่มีประสบการณ์" |
| **การวัดผล (Measurement)** | วัดผลแยกแยะไม่ได้ว่าจุดไหนทำให้คนตัดสินใจ | เห็นผลลัพธ์ A/B Testing ชัดเจน (CTR, CPC, Conversion) |

**ข้อสรุป:** **"สื่อสารใหม่เลย"** โดยสร้าง Ad ตัวใหม่เป็น Dark Post ลิงก์เข้าสู่หน้าบทความ ไม่แก้ทับแอดเดิม

## 2. โครงสร้าง Funnel การยิงโฆษณา (Dual-Track Architecture)

```
┌─────────────────────────────────────────────────────────────────────────┐
│ TRACK A: Cold & Warm Traffic (คนอยากเปลี่ยนสาย / คนติด Tutorial Hell)       │
├─────────────────────────────────────────────────────────────────────────┤
│ 1. ยิง Dark Post Ad ชุดใหม่ (Story & Pain Point Hook)                      │
│    - Hook A: ติด Tutorial Hell ทำตามคลิปได้ แต่ไม่กล้าสมัครงาน?                 │
│    - Hook B: จบไม่ตรงสาย จะหาประสบการณ์แรกจากไหนถ้าไม่มีใครรับ?                 │
│ 2. ปลายทาง: Landing Page บทความ Advertorial                               │
│    URL: /guide/switch-to-developer/                                     │
│ 3. หน้าบทความทำหน้าที่ "กล่อม & สร้างคุณค่า":                                  │
│    - ตีแผ่ความจริงตลาด Dev ยุค AI                                       │
│    - ชี้ทางรอด 4 ขั้นตอน (Git, Enterprise Project, Production Mindset)    │
│    - นำเสนอไม้ตายปิดการขาย: "สิทธิ์ประสานหาที่ฝึกงานพาร์ทเนอร์"               │
│ 4. ปิดการขาย: กดปุ่มทัก LINE ปรึกษาเงื่อนไขสิทธิ์ฝึกงาน / จองสิทธิ์             │
└─────────────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────────────┐
│ TRACK B: Retargeting Hot Audience (คนที่เคยทักแชต / เคยส่องหน้าคอร์ส)      │
├─────────────────────────────────────────────────────────────────────────┤
│ 1. ปรับแอดเดิม หรือสร้าง Retargeting ขนาดเล็ก (งบ 100-150 บาท/วัน)         │
│ 2. กลุ่มเป้าหมาย: Custom Audience คน Engage เพจ / ทักแชตในรอบ 60 วัน      │
│ 3. ชูข้อเสนอใหม่ตรงจุด: "โค้งสุดท้ายรุ่น #24 เพิ่มสิทธิ์ฝึกงานพาร์ทเนอร์"    │
│ 4. ปลายทาง: ทัก LINE ปิดการขายทันที                                      │
└─────────────────────────────────────────────────────────────────────────┘
```

## 3. กฎเหล็กด้านจิตวิทยาการสื่อสาร (Communication Rules)

1. **ห้ามสื่อสารจำนวนที่นั่งที่เหลือเป็นตัวเลขดิบ (เช่น เหลือ 16 ที่นั่ง) ❌**
   - *เหตุผล:* ลูกค้าจะรู้สึกว่ายอดสมัครน้อย คอร์สไม่ได้รับความนิยม หรือคิดว่ายังเหลือเยอะ ไม่ต้องรีบ
2. **ใช้การจำกัดสิทธิ์และความ Exclusive แทน ✅**
   - *ข้อความที่ใช้:* `"รับจำกัดไม่เกิน 20 คนต่อรุ่น เพื่อให้โค้ชดูแลและตรวจโค้ดได้แบบ 1-on-1"`
   - *เหตุผล:* ลูกค้ารู้สึกว่าคอร์สนี้เน้นคุณภาพ ไม่ได้รับคนมั่วซั่ว
3. **ใช้ "วันเปิดเรียน" เป็นตัวสร้างความเร่งด่วน (Urgency by Deadline) ✅**
   - *ข้อความที่ใช้:* `"นับถอยหลัง 3 สัปดาห์สุดท้าย ก่อนเปิดคลาส 5 ต.ค. 69 นี้"`
   - *เหตุผล:* วันที่ไม่เคยคอยใคร บีบให้คนรีบขยับตัวตามธรรมชาติ
4. **วาง Call-to-Action แบบ Soft-Commitment ในขั้นแรก ✅**
   - แทนที่จะบังคับให้จ่ายเงิน 65,000 บาททันที ให้ชวน:
   - `"ทัก LINE ปรึกษา Roadmap และเช็คเงื่อนไขสิทธิ์ประสานงานฝึกงานพาร์ทเนอร์"` เพื่อเปิดโอกาสให้ทีมโค้ช/แอดมินโทรคุยหรือแชตปิดการขาย

## 4. Technical & Campaign Setup Checklist

### 4.1 การตั้งค่า Meta Ads Manager (Facebook)
- [ ] **Campaign Objective:** `Leads` หรือ `Traffic` (เน้น Optimize เป็น Landing Page Views)
- [ ] **Ad Set Configuration:**
  - **Daily Budget:** 300 - 500 บาท/วัน
  - **Placements:** Facebook Feed, Instagram Feed (ปิด Audience Network เพื่อลด Traffic ปลอม)
  - **Target Audience:** อายุ 22 - 38 ปี, ความสนใจ: Software Development, Programming, Web design, Career Transition
- [ ] **Ad Level (Dark Post):**
  - เลือก Create Ad (Dark Post)
  - ใช้ Copywriting จาก `docs/ads/facebook-dark-ads-guide.md`
  - URL ลิงก์ปลายทาง: `https://codecampthailand.com/guide/switch-to-developer/?utm_source=facebook&utm_medium=darkpost&utm_campaign=career_switch_guide`

### 4.2 การเตรียมระบบรองรับ (Conversion & Follow-up)
- [ ] ตรวจสอบว่า Meta Pixel และ Google Analytics / Umami ตรวจจับหน้า `/guide/switch-to-developer/` ครบถ้วน
- [ ] ตั้ง Quick Reply ใน LINE Official Account เตรียมสคริปต์ตอบเรื่อง **"สิทธิ์ฝึกงานพาร์ทเนอร์"** ทันทีเมื่อมีคนทักจากหน้า Guide
- [ ] ทีมที่ปรึกษา (Admin/Coach) เตรียมโทรคุย 1-on-1 หากผู้สนใจต้องการสอบถามเรื่องพื้นฐานและการันตีงาน
