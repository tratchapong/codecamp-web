## Course Positioning

Workshop สำหรับ Developer หรือผู้ที่มีพื้นฐาน Web Development ที่ต้องการเรียนรู้ Workflow การพัฒนา Web App ยุคใหม่แบบลงมือทำจริง

เน้นการทำงานแบบ **Builder / Developer Workflow** ตั้งแต่ UI Design, Spec-Driven Development, Project Planning, Fullstack Development, Debugging, AI Agent ไปจนถึง Deploy ขึ้น Production

### เหมาะสำหรับ

- Developer / Programmer
- ผู้ที่มีพื้นฐาน HTML / CSS / JavaScript
- ผู้ที่เคยสร้างเว็บไซต์หรือ Web App มาก่อน
- ผู้ที่อยากเริ่มนำ AI มาช่วยจัด Workflow การพัฒนาเว็บให้เป็นระบบ
- ผู้ที่อยากสร้าง Fullstack Web App ด้วย Next.js และ AI
- ผู้ที่อยากเข้าใจการควบคุม AI Agent ด้วย Spec จากการใช้งานจริง
