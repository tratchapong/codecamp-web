## 2. การวางตำแหน่งผลิตภัณฑ์และกลุ่มเป้าหมาย (Product Positioning & Target Audience)

### 2.1 Positioning
หลักสูตรระดับ **Entry / Self-paced Tier** ของ CodeCamp Thailand เน้นการเรียนรู้ด้วยตนเองผ่านเนื้อหาคุณภาพระดับ Bootcamp จัดตารางเรียนได้ตามความสะดวกของตนเอง ในราคาที่เข้าถึงง่ายที่สุด

### 2.2 กลุ่มเป้าหมายที่เหมาะสม (Target Audience)
- **คนทำงานประจำหรือนักศึกษาที่มีเวลาไม่แน่นอน:** ไม่สามารถเข้าเรียนสดตามเวลาที่กำหนดในวันธรรมดาหรือวันเสาร์-อาทิตย์ได้
- **ผู้ที่ต้องการเรียนรู้ตามความเร็วของตนเอง (Self-paced Learners):** สามารถกลับมาทบทวนซ้ำในหัวข้อที่ยาก หรือเร่งเรียนในหัวข้อที่มีพื้นฐานอยู่แล้ว
- **ผู้ที่ต้องการประหยัดงบประมาณ:** ต้องการเนื้อหาครอบคลุม Fullstack Development คุณภาพระดับ Bootcamp โดยจ่ายในราคา 15,000 บาท
- **ผู้ที่ต้องการปูพื้นฐานเพื่อย้ายสายงานแบบค่อยเป็นค่อยไป:** ยังไม่พร้อมลาออกจากงานเพื่อเข้า Onsite Bootcamp เต็มเวลา

## 4. จุดเด่นและสิทธิประโยชน์ (Key Benefits & Highlights)

1. **ยืดหยุ่นสูงสุด (Maximum Flexibility):** จัดเวลาเรียนได้เอง 24 ชั่วโมง เรียนจากที่ไหนก็ได้ ทุกอุปกรณ์
2. **เนื้อหาเข้มข้น ครอบคลุม Fullstack:** เรียนตั้งแต่พื้นฐาน Web Foundations, JavaScript ขั้นสูง, React Frontend ไปจนถึง Node.js Backend และ Database
3. **ทีม TA Support ดูแลใกล้ชิดตลอด 6 เดือน:** แม้เป็นคอร์สออนไลน์ แต่ไม่ปล่อยให้เรียนตามลำพัง สามารถสอบถามโค้ดที่ติดบั๊กและข้อสงสัยผ่านช่องทางระบบ Support
4. **ระบบ Assignment & Quizzes:** มีการบ้านและข้อสอบย่อยเพื่อวัดผลความเข้าใจในแต่ละบทเรียน
5. **Capstone Project:** ได้ลงมือทำโปรเจกต์ใหญ่ (Full-stack Web Application) เพื่อรวบรวมทักษะทั้งหมดมาประยุกต์ใช้งานจริง
6. **Certificate of Completion:** ได้รับใบประกาศนียบัตรรับรองจากสถาบันเมื่อส่งการบ้านและผ่านเกณฑ์ Capstone Project

## 5. ขอบเขตและข้อจำกัดของหลักสูตร (Scope & Boundaries)

> [!IMPORTANT]
> เพื่อป้องกันความสับสนกับหลักสูตร Tier สูงกว่า (**Fullstack Live Streaming 35,000.-** และ **Fullstack Weekday Onsite 65,000.-**) ต้องสื่อสารข้อจำกัดของหลักสูตรนี้ให้ชัดเจน:

- ❌ **ไม่มีการเรียนสด (No Live Streaming):** ผู้เรียนเรียนผ่านวิดีโอบันทึกการสอน ไม่มีการสอนสดแบบ Real-time
- ❌ **ไม่มีสิทธิ์เข้าร่วมงาน Demo Day & Speed Interview:** งาน Demo Day ต่อหน้า Tech Leads และบริษัทพาร์ทเนอร์สงวนสิทธิ์เฉพาะผู้เรียน Live Streaming และ Onsite เท่านั้น
- ❌ **ไม่มีบริการ Job Matching / ส่งต่อ CV:** คอร์สเน้นให้ความรู้และสร้างทักษะ ไม่มีบริการเชื่อมต่อบริษัทจัดหางานโดยตรง
- ❌ **ไม่มี Group Project:** ทำโปรเจกต์เดี่ยว (Capstone Project) ไม่มีการจัดกลุ่มหรือจำลอง Scrum/Agile ทำงานร่วมกันแบบ Onsite Bootcamp
- ❌ **ไม่มีสิทธิ์ลดหย่อนภาษี 250% ของ สอวช.:** หลักสูตรไม่ได้ผูกกับรหัสรับรอง สอวช. (TPC690045)

## 6. รายละเอียดหลักสูตร (Curriculum Breakdown)

หลักสูตรแบ่งออกเป็น 5 Modules ครอบคลุมทักษะการสร้าง Web Application ตั้งแต่ก้าวแรก:

### Module 1: Foundations (พื้นฐานการสร้างเว็บและเครื่องมือ)
- **Introduction to Computer Science:** หลักการทำงานของคอมพิวเตอร์และเว็บ
- **Terminal with Bash:** การใช้งาน Command Line เบื้องต้นที่จำเป็นสำหรับนักพัฒนา
- **HTML5 & CSS3 Essentials:** โครงสร้างเว็บ, Semantic Tags, การจัดหน้าและจัดสไตล์
- **Git & GitHub:** การควบคุมเวอร์ชัน (Version Control), การ Commit, Branch และ Push งานขึ้น GitHub

### Module 2: JavaScript (การเขียนโปรแกรมและการฝึก Logic)
- **JavaScript Basic to Advanced:** ตัวแปร (let, const), Data Types, Operators, Control Flow (If-Else, Loops), Functions และ ES6+ Syntax
- **JavaScript DOM:** การเข้าถึงและจัดการ Document Object Model, การดักจับ Event การคลิกและฟอร์ม
- **Asynchronous Programming:** ทำความเข้าใจ Callbacks, Promises และ Async/Await
- **Fetch API & REST API:** การส่ง Request (GET, POST, PUT, DELETE) และดึงข้อมูล JSON มาแสดงผลบนหน้าเว็บ

### Module 3: Frontend Framework (การสร้าง UI สมัยใหม่ด้วย React)
- **React Fundamentals:** JSX, Component Architecture, Props และ Component Reusability
- **React Hooks & State:** `useState`, `useEffect` และการจัดการ State ภายในหน้าเว็บ
- **React Router:** การทำ Single Page Application (SPA) และการเปลี่ยนหน้าเว็บ (Client-side Routing)
- **Global State Management:** การแชร์และจัดการ State ระดับ Application
- **Form Validation:** การจัดการ Form State และตรวจสอบความถูกต้องของข้อมูลก่อนส่ง
- **UX / UI Design:** หลักการจัด Layout และพื้นฐานการออกแบบเว็บให้ใช้งานง่าย

### Module 4: Backend & Workshop (การพัฒนา Server, ฐานข้อมูล และโปรเจกต์รวม)
- **Node.js Essentials:** พื้นฐาน Node.js Runtime, Modules และ NPM Ecosystem
- **Database Management:** การออกแบบ Schema ฐานข้อมูล, การสร้างตาราง และการจัดการข้อมูลด้วย CRUD
- **Connecting Frontend & Backend:** การสร้าง RESTful API และเชื่อมต่อไปยัง Frontend React
- **Workshop: Fakebook (Full-stack):** การพัฒนาโปรเจกต์จำลองระบบ Social Media ที่มีการโพสต์ แสดงผล เชื่อมต่อฐานข้อมูลทั้งระบบ

### Module 5: Extras & Career Resources (เนื้อหาเสริมเพิ่มเติม - Optional)
- **Docker Fundamentals:** พื้นฐาน Containerization สำหรับการจำลอง Environment
- **Test Driven Development (TDD):** แนวคิดการเขียน Unit Test เพื่อความเสถียรของโปรแกรม
- **How to Write a Resume:** เคล็ดลับและแนวทางการเขียน Resume สำหรับสายโปรแกรมเมอร์
- **Node.js Advanced (Extra):** เทคนิคขั้นสูงเพิ่มเติมสำหรับงาน Backend

## 7. การวัดผลและเกณฑ์การรับใบประกาศนียบัตร (Assessment & Certification)

1. **Progress & Exercises:** ทำแบบฝึกหัดและการบ้านตามแต่ละบทเรียน
2. **Quizzes:** ทำแบบทดสอบวัดความรู้หลังจบบทเรียน
3. **Capstone Project:** พัฒนา Web Application ฉบับสมบูรณ์ (Fullstack) ตามเกณฑ์ที่กำหนด และส่งตรวจผ่านระบบ
4. **Certificate of Completion:** เมื่อผ่านเกณฑ์การประเมิน Capstone Project จะได้รับใบประกาศนียบัตรอิเล็กทรอนิกส์จาก CodeCamp Thailand

## 9. กฎเหล็กการสื่อสารการตลาดและการขาย (Communication Rules)

1. **ห้ามการันตีหรือสัญญาว่าได้เข้า Demo Day:** ต้องย้ำชัดเจนว่า Demo Day สงวนสิทธิ์เฉพาะรุ่น **Live Streaming** และ **Onsite** เท่านั้น หากผู้เรียนต้องการพบปะบริษัทพาร์ทเนอร์จริง ต้องแนะนำคอร์ส Live Streaming (35,000 บาท) ขึ้นไป
2. **ระบุระยะเวลา Support ชัดเจน:** ชี้แจงให้เห็นว่าการช่วยเหลือจาก TA มีระยะเวลา 6 เดือน และสิทธิ์การเข้าชมวิดีโอมีอายุ 1 ปี
3. **ชูจุดขายเรื่องความยืดหยุ่นและคุ้มค่า:** เหมาะสำหรับคนที่ต้องการความรู้และทักษะทำเว็บ แต่ตารางชีวิตไม่เอื้อต่อการเรียนสด หรือผู้ที่มีงบประมาณจำกัด
