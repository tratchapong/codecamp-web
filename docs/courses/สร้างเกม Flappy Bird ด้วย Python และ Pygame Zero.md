# **สร้างเกม Flappy Bird ด้วย Python และ Pygame Zero**  

ชื่อคอร์สทางเลือกรอง  
*1\. Python Zero to Flappy Bird: เรียนพื้นฐานผ่านการสร้างเกม*  
*2.Build Your First Python Game with Pygame Zero*  
*3.สร้าง Flappy Bird ด้วย Pygame Zero*

**วัตถุประสงค์ :** ผู้เรียนจะสามารถ:

* ติดตั้ง Python, Code Editor และ Pygame Zero  
* เข้าใจคำสั่ง Python ที่จำเป็นต่อการสร้างเกม  
* ใช้ตัวแปร เงื่อนไข ฟังก์ชัน List และ Module ได้  
* เข้าใจพิกัด การเคลื่อนที่ และ Game Loop  
* แสดงภาพ ตัวละคร ข้อความ และเล่นเสียงด้วย Pygame Zero  
* รับคำสั่งจากคีย์บอร์ดและตรวจสอบการชน  
* สร้างเกม Flappy Bird ที่เล่นและเริ่มใหม่ได้  
* นำหลักการไปดัดแปลงความยาก ภาพ เสียง และกติกาของเกมได้

# **Course outline**

## **Day 1: ติดตั้งและพื้นฐาน Python**

* ติดตั้ง Python, VS Code และ Pygame Zero  
* ตัวแปร ชนิดข้อมูล และการคำนวณ  
* เงื่อนไข `if`, `elif`, `else`  
* Workshop Python พื้นฐาน

  ## **Day 2: Python สำหรับสร้างเกม**

* Functions  
* List และ Index  
* Module และ `random`  
* Object, Attribute และ Method  
* Workshop เตรียมข้อมูลตัวละครและอุปสรรค

  ## **Day 3: พื้นฐาน Pygame Zero**

* โครงสร้างโปรเจกต์และระบบพิกัด  
* การแสดงภาพ ตัวละคร ข้อความ และเสียง  
* การรับคำสั่งจากคีย์บอร์ด  
* การเคลื่อนที่ แรงโน้มถ่วง การชน และคะแนน

  ## **Day 4: Workshop สร้างเกม Flappy Bird**

* สร้างฉาก นก และท่อ  
* ทำระบบบินและการเคลื่อนที่  
* ทำระบบตรวจการชนและนับคะแนน  
* ทำหน้าเริ่มเกม Game Over และ Restart  
* ทดสอบและปรับความยากของเกม
