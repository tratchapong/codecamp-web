# Course Specification: Fullstack Live Streaming #24

> สเปกสำหรับให้ Agent แตกคอร์ส Live Streaming ออกจาก Fullstack CodeCamp Weekday เดิม
> โดยใช้เนื้อหาหลักและตารางเรียนร่วมกับรุ่น Onsite แต่แยก Product / Course Page / ราคา / สิทธิ์ให้ชัดเจน

---

## 1. เป้าหมาย

สร้างคอร์สใหม่ในระบบชื่อ **Fullstack Live Streaming #24** แยกออกจากคอร์ส **Fullstack CodeCamp Weekday #24 (Onsite)**

คอร์ส Streaming ไม่ใช่ Recorded Course และไม่ใช่เพียง option ในหน้าคอร์ส Onsite แต่เป็นสินค้าแยกที่มีราคาและรายละเอียดของตัวเอง

ผู้เรียน Streaming:
- เรียนสดออนไลน์พร้อมกับรุ่น Onsite
- ใช้ตารางเรียนและเนื้อหาหลักเดียวกัน
- เริ่มและจบพร้อมกัน
- ถามคำถามระหว่างเรียนสดได้
- ถามคำถาม/ขอความช่วยเหลือต่อผ่าน Community Support ได้
- ทำ Project เดี่ยว
- มีการประเมินและสัมภาษณ์จาก Project เดี่ยว
- สามารถเข้าร่วม Demo Day ตามเงื่อนไขของหลักสูตร
- ไม่เข้าร่วม Project กลุ่มของรุ่น Onsite

## 2. Product Positioning

ระบบควรแยกสินค้าออกเป็น 3 ระดับอย่างชัดเจน

| Product | รูปแบบ | ราคา |
|---|---|---:|
| Online Fullstack | Recorded / Self-paced | 15,000 บาท |
| **Fullstack Live Streaming** | Live Online / Cohort-based | **35,000 บาท** |
| Fullstack CodeCamp Weekday | Onsite Bootcamp | 65,000 บาท |

แนวคิดของแต่ละระดับ:

- **Online 15,000** = เรียนด้วยตัวเอง
- **Live Streaming 35,000** = เรียนสด มีตาราง มีผู้สอน/ทีมดูแล ถามได้ และเรียนจนจบพร้อมรุ่น
- **Onsite 65,000** = Bootcamp เต็มรูปแบบ เรียนที่สถาบันและมีประสบการณ์ทำ Project กลุ่ม

## 4. Learning Experience & Target Audience

### Target Audience (กลุ่มเป้าหมายหลัก)
- **คนทำงานประจำ:** ผู้ที่ต้องการเปลี่ยนสายงานสู่ Developer แต่ไม่อยากลาออกจากงานประจำ หรือไม่สะดวกเดินทางมาเข้าเรียน Onsite ที่สถาบันพญาไท
- **ผู้ที่ต้องการความยืดหยุ่น:** ผู้ที่ต้องการเนื้อหาและบรรยากาศเข้มข้นแบบ Bootcamp เต็มรูปแบบ แต่ต้องการจัดเวลาดูคลิปบันทึกย้อนหลังในช่วงค่ำหรือวันหยุดเสาร์-อาทิตย์

### Live Class & Flexible Catch-up
- **ถ่ายทอดสดตรงจากห้อง Onsite:** จันทร์ - ศุกร์ 09:00 - 17:00 น. สตรีมสดตามเวลาจริง ได้เนื้อหา สไลด์ โค้ดดิ้ง และบรรยากาศสดพร้อมห้องเรียน Onsite
- **Real-time Q&A:** สามารถพิมพ์ถามคำถามและโต้ตอบระหว่างเรียนสดได้
- **ดูบันทึกย้อนหลังได้ 1 ปีเต็ม:** หากติดงานช่วงกลางวัน ไม่สะดวกดูสด สามารถจัดสรรเวลาดูคลิปบันทึกย้อนหลังในช่วงค่ำหรือเสาร์-อาทิตย์ได้อย่างอิสระตลอด 1 ปีเต็ม

### Community Support
ผู้เรียน Streaming สามารถใช้ Community Support สำหรับ:
- ถามปัญหาเกี่ยวกับบทเรียนและเนื้อหาการสอน
- ปรึกษาเมื่อโค้ดมีบั๊ก หรือติดขัดในการทำ Assignment
- ขอคำแนะนำในการพัฒนา Individual Final Project
- ปรึกษาทีมโค้ชและ Mentors ตลอดระยะเวลาการเรียน

## 6. Project Structure

### Streaming

ใช้ **Individual Project / Project เดี่ยว**

ผู้เรียนแต่ละคนต้องสร้าง Project ของตัวเองเพื่อใช้เป็น:
- Final Project
- Portfolio
- หลักฐานการประเมินความสามารถ
- หัวข้อสำหรับ Final Interview / Project Review
- ผลงานสำหรับ Demo Day ตามเกณฑ์ที่กำหนด

### Onsite

ยังคงใช้ Project กลุ่มตามรูปแบบ Bootcamp เดิม

ดังนั้นความแตกต่างสำคัญคือ:

**Streaming = Individual Project**

**Onsite = Group Project / Team Development Experience**

ไม่ควรนำ Project กลุ่มมาเป็น requirement ของ Streaming

## 7. Assessment

การสอบระหว่างหลักสูตรใช้เป็น **Checkpoint** เพื่อติดตามความเข้าใจและ Progress ของผู้เรียน

สำหรับผู้เรียน Streaming การสอบสามารถทำ Online ได้โดยไม่จำเป็นต้องมีระบบ Proctoring ที่ซับซ้อน

การประเมินผลหลักควรให้น้ำหนักกับ:

1. Progress ระหว่างเรียน
2. Assignment / Coding Work
3. Individual Final Project
4. Project Presentation / Demo
5. Final Interview / Project Review

แนวคิดหลัก:

> ผู้เรียนสามารถใช้เครื่องมือที่เหมาะสมในการพัฒนาได้ รวมถึง AI แต่ต้องสามารถอธิบาย Project และสิ่งที่ตัวเองสร้างได้

---

## 8. Final Project Interview

หลังหรือช่วงท้ายของ Project ให้มีการ Review / Interview จาก Project เดี่ยว

หัวข้อที่สามารถใช้ประเมิน เช่น:
- Project นี้แก้ปัญหาอะไร
- Architecture โดยรวมเป็นอย่างไร
- Frontend / Backend เชื่อมกันอย่างไร
- Database ออกแบบอย่างไร
- Authentication ทำงานอย่างไร
- ทำไมเลือกวิธีนี้
- อธิบาย Code สำคัญใน Project
- แก้ Requirement หรือ Bug จากโจทย์เพิ่มเติม
- อธิบายส่วนที่ใช้ AI ช่วยสร้าง

เป้าหมายไม่ใช่การจับผิดว่าใช้ AI หรือไม่ แต่เป็นการตรวจสอบว่า:

**ผู้เรียนเข้าใจและสามารถรับผิดชอบ Project ที่ตัวเองส่งได้**

## 9. Demo Day

ผู้เรียน Streaming มีสิทธิ์เข้าร่วม Demo Day ตามเงื่อนไขของหลักสูตร

Demo Day สามารถใช้สำหรับ:
- Present Project

- Interview Opportunity ตามรูปแบบของแต่ละรุ่น

เกณฑ์การได้ Present หรือรายละเอียดกิจกรรมสามารถกำหนดเพิ่มเติมตามรูปแบบ Demo Day ของแต่ละ Cohort

## 13. Relationship กับ Fullstack Weekday

Streaming Course ควรเป็น Product แยกในเชิงการขาย แต่สามารถ Share ข้อมูลกับ Fullstack Weekday ได้ เช่น:

- Cohort
- Start Date
- End Date
- Schedule
- Curriculum
- Instructor
- Live Session
- Demo Day Date

ส่วนข้อมูลที่ต้องแยก:

- Price
- Learning Mode
- Course Page / Slug
- Project Type
- Onsite Privileges
- Product Description
- Enrollment

แนวทางข้อมูล:

```text
Fullstack Cohort
├── Onsite Product — 65,000
│   └── Group Project
│
└── Live Streaming Product — 35,000
    └── Individual Project
```

ไม่ควร Duplicate ตารางเรียนทั้งหมดเป็นสองชุดถ้า Architecture ปัจจุบันรองรับการ Share Cohort ได้
