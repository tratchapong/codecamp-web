# Go Web Backend Workshop (Gin)

> สร้าง Backend REST API ด้วย Go ตั้งแต่ Fundamentals ไปจนถึง Production Workflow

**สถานะ:** 🔴 ปิดรับสมัครแล้ว (เปิดเรียนแล้ว)
**รูปแบบ:** 4 วัน (เสาร์–อาทิตย์ × 2 สัปดาห์)  
**เวลา:** 10:00–17:00  
**วันเรียนที่เสนอ:** 12–13 และ 19–20 กันยายน 2569

---

## Course Positioning

คอร์ส Project-based สำหรับ Developer ที่ต้องการเพิ่มทักษะ Backend Development ด้วย **Go + Gin**

ผู้เรียนพัฒนา REST API โปรเจกต์เดียวต่อเนื่องตลอด 4 วัน ตั้งแต่ Go Fundamentals, Routing, Middleware, Database, Authentication ไปจนถึง Testing, Docker และ Deploy

คอร์สไม่ได้ออกแบบเป็น Programming from Zero เต็มรูปแบบ แต่จะ Recap Go Fundamentals ในช่วงต้น เพื่อให้ผู้เรียนที่มาจากภาษาอื่นสามารถตามเนื้อหาได้

### Core Message

**สร้าง Production-ready Backend API ด้วย Go & Gin ผ่านโปรเจกต์จริงใน 4 วัน**

### Main Workflow

**Go → Gin → PostgreSQL → GORM → JWT → Testing → Docker → Deploy**
