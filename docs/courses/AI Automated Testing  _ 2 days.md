# **AI Automated Testing**  

ชื่อคอร์สทางเลือกรอง  
*1\. Autonomous Testing for Devs  : ปล่อยใจให้ AI (MCP) ช่วยเขียน Playwright Test*  
*2\. The AI-Powered Tester: สร้าง Automated Test อัจฉริยะด้วย Playwright & MCP*  
*3\. AI Automated Testing: โค้ดเสร็จ เทสพร้อม ด้วย Playwright และ MCP*

**วัตถุประสงค์ :** เรียนรู้การเขียน Automated Test ตั้งแต่พื้นฐานจนถึงระดับใช้งานจริง สร้างและจัดการระบบ Test ผ่าน Model Context Protocol (MCP) ซึ่งเป็นกระบวนการนำ AI Test Tools มาช่วยลดขั้นตอน ทั้งในสายงาน QA และ SDET (Software Development Engineer in Test) ในยุคปัจจุบัน

**ผู้เรียน :** QA/Tester, Developer ที่ต้องการเขียน E2E Test  
*\* Prerequisites : พื้นฐาน JavaScript/TypeScript*

# **Course outline**

## **Day 1: พื้นฐาน Playwright & โครงสร้างโปรเจกต์**

##  **(เช้า)** 

* แนวคิด Automated Testing คืออะไร ต่างจาก Manual อย่างไร  
* ทำ ความรู้จัก Playwright: จุดเด่นเทียบกับ Selenium/Cypress  
* ติดตั้งและตั้งค่าโปรเจกต์ Playwright  
* Locators, การกระทำ พื้นฐาน (click, fill, type, hover) และ Assertions

##  **(บ่าย)** 

* Page Object Model (POM): หลักการออกแบบและแยก Test Logic  
* Fixtures และการทำ Test Data Management  
* Visual Testing เบื้องต้น (Screenshot comparison)  
* Workshop: เขียน Test ครอบคลุม flow จริง 1 หน้าเว็บด้วย POM


## **Day 2: Advanced Testing & AI-Powered Testing ด้วย MCP**

##  **(เช้า)** 

* API Testing ด้วย Playwright Request Context  
* ผสาน UI Test \+ API Test และจัดการ Authentication/Session  
* CI/CD Integration  
  * GitHub Actions, Parallel Execution, จัดการ Flaky Tests

##  **(บ่าย)** 

* แนะนำ MCP (Model Context Protocol)  
* ภาพรวม Playwright MCP Server  
* ใช้ AI ช่วย generate test case จาก user story และช่วย debug/maintain test ที่ล้มเหลว  
* Capstone Workshop: สร้างชุด Automated Test แบบ End-to-end ด้วย AI  
* สรุปคอร์ส \+ Q\&A
