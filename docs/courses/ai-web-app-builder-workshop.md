## Course Positioning

คอร์สสำหรับผู้เริ่มต้น คนทำงาน เจ้าของธุรกิจ และผู้ที่อยากเริ่มสร้าง Web App ด้วย AI โดยไม่จำเป็นต้องมีพื้นฐานการเขียนโปรแกรมมาก่อน

แนวทางการสอนเน้น **ปูพื้นให้เข้าใจแนวคิดสำคัญของ AI และ Web Development แล้วลงมือทำ Workshop ในแต่ละช่วง** เพื่อให้ผู้เรียนเห็นภาพ Workflow ตั้งแต่เริ่มต้นจน Deploy ขึ้น Internet

### เหมาะสำหรับ

- ผู้เริ่มต้น
- คนทำงาน
- เจ้าของธุรกิจ
- ผู้ที่อยากสร้าง Web App แต่ไม่เคยเขียนโปรแกรม
- ผู้ที่อยากเข้าใจ AI Coding / Agentic Coding แบบเป็นระบบ
