## 3. การวางตำแหน่งผลิตภัณฑ์และจุดเด่น (Positioning & Highlights)

- **Positioning:** สำหรับคนทำงานหรือผู้ที่อยากสร้างเว็บได้ในเวลาที่น้อยที่สุด ไม่ต้องลาออก ไม่ต้องหยุดงาน เรียนเฉพาะเสาร์-อาทิตย์
- **จุดเด่น:**
  1. ได้ทักษะสร้างเว็บครบ Frontend (React) ถึง Backend (Node.js & Prisma) และ Database
  2. เข้าใจโค้ดจริงที่ AI เขียน อ่านโค้ดได้ แก้บั๊กเป็น ไม่ใช่สั่ง Prompt แบบตาบอด
  3. เรียนรู้ผ่าน OpenRouter สลับโมเดลได้หลากหลาย (Claude, GPT-4o, Gemini, Llama) เข้าใจ Token และบริหารต้นทุน AI ได้จริง
  4. บริการจัดอบรม Corporate Training / Private Class สำหรับองค์กรที่ต้องการอัปสกิลทีม

## 4. โครงสร้างหลักสูตร (Curriculum Outline)

- **Day 1–2: พื้นฐานเว็บ + เครื่องมือ AI**
  - โครงสร้างเว็บ HTML & CSS พื้นฐาน
  - การใช้ AI Tools ช่วยเขียนและสร้างหน้าเว็บแรก
  - Workflow: สั่ง AI เขียน → อ่านโค้ด → แก้ไขเอง
  - Workshop: พัฒนาหน้าเว็บ UI
- **Day 3–4: คิดแบบโปรแกรมเมอร์ (Logic & DOM)**
  - Logic การเขียนโปรแกรมพื้นฐาน
  - ควบคุมองค์ประกอบเว็บด้วย DOM & Event
  - ดึงข้อมูลจาก API มาแสดงผลบนหน้าเว็บ
  - Workshop: ระบบค้นหาและตัวกรองสินค้า
- **Day 5–6: Frontend ด้วย React**
  - โครงสร้าง React: Component, Props และ State
  - จัดการ Form, List และ Routing หลายหน้า
  - Workshop: หน้าแสดงรายการสินค้าและรายละเอียด
- **Day 7–8: Backend + Database ครบวงจร**
  - พื้นฐาน Server & Database (Node.js & Prisma)
  - ระบบสมัครสมาชิกและเข้าสู่ระบบ (Auth)
  - เชื่อมต่อ Frontend เข้ากับ Backend แบบ Full-stack
