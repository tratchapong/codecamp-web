5. **Career Preparation & Mentorship:** เวิร์กชอปเตรียมความพร้อมสมัครงาน ทั้งการเขียน Resume, พอร์ตโฟลิโอ GitHub/Web app และการจำลองสัมภาษณ์ (Mock Interview)
6. **Demo Day & Speed Interview:** ปิดคอร์สด้วยงาน Demo Day นำเสนอผลงานต่อหน้า HR, Tech Lead และผู้บริหารจากบริษัทพาร์ทเนอร์โดยตรง
7. **การันตีที่ฝึกงานกับบริษัทพาร์ทเนอร์ (สิทธิพิเศษเฉพาะ Onsite):** หากเรียนจบแล้วยังไม่ได้งาน สถาบันการันตีที่ฝึกงานกับบริษัทพาร์ทเนอร์ เพื่อให้คุณเริ่มต้นเก็บเกี่ยวประสบการณ์ทำงานจริงกับทีม Tech ทันที
8. **Job Matching & Connection:** มีบริการแนะนำและส่งต่อ CV/Profile ให้กับเครือข่ายบริษัทพาร์ทเนอร์อย่างต่อเนื่องหลังเรียนจบ
9. **ใบประกาศนียบัตร:** ได้รับ Certificate of Completion เมื่อเรียนจบและผ่านเกณฑ์หลักสูตร

## 5. รายละเอียดหลักสูตร (Curriculum Breakdown)

หลักสูตรแบ่งออกเป็น 5 Phase ครอบคลุมการพัฒนา Web Application แบบ Fullstack ตั้งแต่พื้นฐานจนถึงเทคโนโลยีสมัยใหม่และการประยุกต์ใช้ AI

### Phase 1: พื้นฐานการสร้างเว็บ (Web Foundations)
- วิธีคิดแบบโปรแกรมเมอร์ (Computational Thinking) & คอมพิวเตอร์เบื้องต้น
- การสร้างหน้าเว็บด้วย HTML5 & CSS3 ตั้งแต่เริ่มต้น
- การจัด Layout และ Responsive Design รองรับทุกขนาดหน้าจอ (Desktop, Tablet, Mobile)
- การบันทึกและจัดการเวอร์ชันโค้ดอย่างเป็นระบบด้วย Git & GitHub

### Phase 2: เขียนโปรแกรมและฝึก Logic ด้วย JavaScript (Programming Logic)
- Logic พื้นฐานในการเขียนโปรแกรม: ตัวแปร, เงื่อนไข (If-Else), ฟังก์ชัน (Functions), การวนซ้ำ (Loops)
- การควบคุมและปฏิสัมพันธ์บนหน้าเว็บด้วย DOM (Document Object Model) & Events
- การดึงข้อมูลจากภายนอกผ่าน API (Fetch API / REST API) มาแสดงผลบนหน้าเว็บ

### Phase 3: Frontend สมัยใหม่ด้วย React (Modern Frontend Development)
- โครงสร้าง Component Architecture และการรับส่งข้อมูลผ่าน Props
- การจัดการสถานะข้อมูล (State Management) และการอัปเดต UI แบบ Real-time
- การสร้าง Web Application แบบหลายหน้า (Routing) และระบบฟอร์มรับข้อมูลพร้อม Validation

### Phase 4: Backend, Database & Authentication
- การสร้าง RESTful API ด้วย Node.js & Express เชื่อมต่อ Frontend กับ Server
- การออกแบบและจัดการฐานข้อมูล (Database Design & SQL / NoSQL / ORM)
- การเชื่อมต่อ Frontend และ Backend แบบครบวงจร (Full-stack Integration)
- ระบบสมัครสมาชิก, การเข้าสู่ระบบ (Authentication & Authorization - JWT) และความปลอดภัยพื้นฐาน

### Phase 5: โปรเจกต์จริง & เตรียมตัวสมัครงาน (Production Projects & Career Prep)
- การอัปเกรดเทคโนโลยีสู่ **Next.js** และ **TypeScript**
- การประยุกต์ใช้ **AI Agents** ในการพัฒนาโปรเจกต์
- การพัฒนาโปรเจกต์กลุ่มแบบทีม Developer (Agile / Scrum workflow)
- การจัดทำ Resume, GitHub Portfolio และเตรียมตัวสัมภาษณ์งาน
- กิจกรรม **Demo Day** นำเสนอผลงานต่อบริษัทพาร์ทเนอร์จริง
