> 4 วัน สร้าง Digital Wallet API ด้วย Go + Gin

เน้น Deposit / Withdraw / Transfer / Transaction History / Authentication

> เขียน JavaScript / Python / Java อยู่แล้ว อยากเพิ่ม Go เป็น Backend Skill?

เน้นว่าไม่ต้องเชี่ยวชาญ Go มาก่อน แต่ควรมีพื้นฐาน Programming

**3. Production Backend Angle**

> จาก REST API ไปจนถึง Testing, Docker & Deploy

เน้นว่าไม่ได้เรียนแค่ CRUD แต่ไปถึง Production Workflow
